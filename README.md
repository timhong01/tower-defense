# 潮汐要塞 · Naval Tower Defense

一款單一 HTML 檔案的網頁小遊戲，使用 [Three.js](https://threejs.org/) 打造 3D 海上戰場。專為手機直向畫面設計，採波數制塔防玩法（無關卡，無限波數）。

## 立即遊玩

- **線上遊玩**：開啟 GitHub Pages（若已啟用）→ `https://timhong01.github.io/tower-defense/`
- **本機遊玩**：直接用瀏覽器開啟 [`index.html`](index.html) 即可，無需安裝任何東西（需連網以載入 Three.js 與字型）。

> 建議使用手機直向、或將桌面瀏覽器視窗調整為直向比例，以獲得最佳體驗。

## 玩法說明

- 🏰 **要塞**：畫面中央的要塞本身就是一座砲塔，會自動朝射程內的敵艦開火。護盾歸零即遊戲結束。
- 🚢 **敵艦**：從四面八方的海面朝中央要塞自由方向衝來，沒有固定路徑。撞到要塞會扣護盾、撞到砲塔會扣砲塔耐久。
- 🗼 **砲塔**：只有一種塔，可在海面自由點擊放置。每座塔各自獨立擁有血量、火力等級與射速等級。
- ✦ **得分與升級**：每擊殺 1 艘敵艦得 1 分，且**每成功守住一波額外贈送 1 點**。每滿 5 分可獲得一次「抉擇」——透過畫面下方的常駐按鈕，選擇**建造新塔**或**升級**。升級需先點選一座塔（或要塞），再從「射速／火力／射程／補血」四選一，只影響選定的那一座。
- ⏳ **開局**：起始即有 5 點資源與 10 秒準備倒數，可先行佈署。

## 塔的視覺回饋

| 屬性 | 視覺變化 |
| --- | --- |
| 血量（hp） | 塔本體大小（受傷變小、補血變大），頭頂有血條 |
| 火力等級（dmgLv） | 砲管變長 |
| 射速等級（frLv） | 砲管顏色隨等級變熱（灰 → 黃 → 橘 → 紅），開火時有槍口閃光 |
| 射程等級（rangeLv） | 射程圈半徑變大 |

敵艦也會隨波數「升級」：越後面的波次，敵艦船體越大、船帆越多、配色越兇猛，並逐步長出撞角、側舷火炮與旗幟（共 5 個外觀階層）。

## 美術風格

- 3D 動態海浪，麥塊（Minecraft）風格的量化方塊感：高度階梯化、色階光影，而非平滑漸層。
- 鏡頭為垂直由上往下俯視，開局後會隨時間緩慢 zoom out 拉遠，逐漸展開可視海域（有上限，不會無限拉遠）。

## 難度調整

所有可調參數集中在 [`index.html`](index.html) 最上方的 `CONFIG` 物件中，方便調整難度曲線，例如：

- `FIELD_RADIUS`、`BASE_MAX_HP`、`MAX_TOWERS`
- 塔基礎值：`range` / `cooldown` / `damage` / `hp`
- 敵人成長：`baseHp`、`hpPerWave`、`baseSpeed`、`speedPerWave`、`speedCap` 等
- 波數設定：每波敵數、生成間隔、波間休息時間

## 技術

- 單一 HTML 檔案，無建置流程、無相依套件安裝。
- Three.js（r128，透過 CDN 載入）負責 3D 渲染，海面與天空使用自訂 GLSL shader。
