# 潮汐要塞 · Naval Tower Defense

一款單一 HTML 檔案的網頁小遊戲，使用 [Three.js](https://threejs.org/) 打造 3D 海上戰場。專為手機直向畫面設計，採**固定時間開波**的無盡塔防（無關卡，撐越久越難）。

## 立即遊玩

- **線上遊玩**：`https://timhong01.github.io/tower-defense/`（需於該 repo 的 Settings → Pages 啟用）
- **本機遊玩**：直接用瀏覽器開啟 [`index.html`](index.html) 即可，無需安裝（需連網以載入 Three.js 與字型）。

> 建議手機直向遊玩；桌面可用右側 ⛶ 全螢幕鈕獲得最佳體驗。介面預設英文，偵測到繁體中文系統時自動切換。

## 玩法說明

- 🏰 **要塞**：畫面中央的要塞本身就是一座砲塔，會自動朝射程內的敵艦開火。護盾歸零即遊戲結束。
- 🗼 **砲塔**：只有一種塔，可在海面自由點擊放置（上限 8 座），各自獨立擁有血量與各項等級。
- ✦ **得分與升級**：每擊殺 1 艘敵艦得 1 分、每撐過一波再 +1；每 5 點可**建塔**或**升級**。升級需先點選一座塔（或要塞），從「射速／火力／射程／補血」擇一（長壓可連續升級）；選中**要塞**時另有專屬的「🔧 維修電流」升級——會定期電擊自動修復當下最受損的砲塔。
- 🗑️ **拆除**：可拆掉一座砲塔，退還其投入點數的 ⅓，重新佈署到更好的位置。
- ⏱️ **固定時間開波**：每隔固定間隔（預設 11 秒）就開下一波，**不等清場**——沒擊沉的敵艦會留在場上，壓力持續累積，直到你守不住。開局有 5 點資源與 10 秒準備倒數。

## 敵艦種類與登場時機

所有敵艦都從**畫面外緣**隨機方位駛入、以船隻般的弧線轉向；每個敵種首次登場時都有 Boss 風格橫幅。

| 敵種 | 首次出現 | 特性 |
| --- | --- | --- |
| 🔴 **撞塔艦** | 第 1 波 | 主力。鎖定當下血量最少的砲塔衝撞，沒有砲塔時直取要塞。 |
| 🛡️ **重甲艦** | 第 6 波 | 血量超厚、速度慢，**蛇行前進**專門吸收火力、掩護友軍。 |
| 🔫 **砲擊艦** | 第 8 波 | 停在射程外**遊走並遠程轟擊**砲塔／要塞，不撞塔——專剋短射程，升射程可壓制。 |
| 🚤 **高速艇** | 第 10 波 | 極速、脆皮，直衝你的防線。 |
| 💚 **補血艦** | 第 12 波 | 不攻擊，**跟隨砲擊艦**、定期治療周圍受損敵艦；不優先清掉它整波會難以殲滅。 |
| 🛳️ **母船** | 第 16 波 | 超大、極慢，待在遠方**從船腹孵出小船**；主力清空後才逼不得已推進。 |

> 敵艦血量隨波數線性成長（`(12 + 波×3) × 該艦種倍率`）；撞塔艦外觀另有 5 個階層，越後面船體越大、船帆越多、越兇猛。

## 操作與介面

- **建塔／升級／拆除**：畫面下方常駐按鈕；點數足夠時有呼吸動畫，不足時反灰。
- **點畫面空白處**：關閉升級面板返回；點其他塔則直接切換升級對象。
- 右側控制列：⏸ **暫停**（半透明視窗）、**加速**（1× / 2× / 3× 循環，測試用）、🔊 **靜音**（偏好記憶）、⛶ **全螢幕**。

## 塔的視覺回饋

| 屬性 | 視覺變化 |
| --- | --- |
| 血量（hp） | 塔本體大小（受傷變小、補血變大），頭頂有血條 |
| 火力等級（dmgLv） | 砲管變長 |
| 射速等級（frLv） | 砲管顏色隨等級變熱（灰 → 黃 → 橘 → 紅）；達下限顯示 MAX |
| 射程等級（rangeLv） | 射程圈半徑變大 |

要塞主砲升級時，其砲管也會同步變長／變熱。

## 美術與音效

- 3D 動態海浪，麥塊（Minecraft）風格的量化方塊感（自訂 GLSL shader）；垂直俯視、開局後緩慢 zoom out。
- 🔊 **音效與 BGM 全部以 Web Audio 即時合成**（無音檔、離線可用）：開火／爆炸／建塔／升級／維修電流／波次／登場等音效，加上 128 BPM 的循環戰鬥配樂；右側 🔊 一鍵靜音。
- iOS 音訊已處理背景中斷後的自動恢復（任何觸控都會 resume）。

## 難度調整

所有可調參數集中在 [`index.html`](index.html) 最上方的 `CONFIG`：

- `FIELD_RADIUS`、`BASE_MAX_HP`、`MAX_TOWERS`、`UPGRADE_COST`、`DEMOLISH_REFUND_DIV`
- 塔基礎值 `TOWER`、升級 `UPGRADE`、要塞維修 `REPAIR`
- 敵人成長與各艦種倍率 `ENEMY`（含 `tank` / `gunner` / `speed` / `healer` / `carrier`）
- 波數節奏 `WAVE`：`waveInterval`（開波間隔）、每波敵數、各敵種 `*FromWave` 登場波與數量上限

## 多語系（i18n）

介面文字集中在檔案頂部的 `I18N` 字典（`{en, zh}`）。語系由 `navigator.language` 判斷（非中文 fallback 英文），並預留 `window.__NTD_LANG` 供外部平台 SDK（如 CrazyGames）覆寫。

## 技術

- 單一 HTML 檔案，無建置流程、無相依套件安裝、零外部素材。
- Three.js（r128，透過 CDN 載入）負責 3D 渲染，海面與天空使用自訂 GLSL shader。

版本演進紀錄見 [`CHANGELOG.md`](CHANGELOG.md)。
